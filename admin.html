Salva / Carica

📋 Come funziona

Tutto quello che modifichi qui viene salvato solo nel tuo browser. Per metterlo online devi:

  1. Cliccare "⬇ Esporta data.json" qui sotto — scarica un file
  2. Andare sul tuo repository GitHub (l'ho creato per te seguendo la guida)
  3. Cliccare sul file data.json esistente
  4. Cliccare l'icona della matita (✏ Edit) in alto a destra
  5. Cancellare il contenuto vecchio, incollare quello nuovo, e cliccare "Commit changes"
  6. Fatto! Sito e launcher si aggiornano automaticamente entro qualche minuto.
⬇ Esporta (per pubblicare)

Scarica il file data.json con i tuoi dati attuali, da caricare su GitHub.

⬆ Importa (per caricare dati esistenti)

Se hai già un data.json (es. lo hai scaricato da GitHub), caricalo qui per modificarlo.

🗑 Reset

Cancella tutti i dati locali e ricomincia da zero. Non tocca quelli online.
